Tcl
===

Исходный фронтенд — модуль Tcl. Каждая команда это обычная C++ функция,
которую SWIG превращает в команду Tcl, а значения по умолчанию берутся из
сигнатуры C++ — поэтому в скрипте можно написать
``grid_get -12 12 0.2 -12 12 0.2`` и не указывать имя сетки. Полный список
команд с синтаксисом, аргументами, умолчаниями и описаниями — в
:doc:`commands`.

Фронтенд необязателен и по умолчанию выключен; собирайте с
``-DSURFIT_BUILD_TCL=ON``, для чего нужны ``tcl-dev`` и SWIG.

Запуск скрипта
--------------

.. code-block:: tcl

   load libtclsurfit[info sharedlibextension]

   clear_data
   set map_name "map_area"
   set tol 5.01187e-006

   area_read "data/area1.txt" "area1"

   grid_get -12 12 0.2 -12 12 0.2

   area 10 "area1"
   completer 1 1.6

   surfit
   surf_save "area.dat" "map_area"

.. code-block:: bash

   export LD_LIBRARY_PATH="$PWD/bin:$LD_LIBRARY_PATH"
   cd examples/surfit/tests
   tclsh area.tcl

Плагин форматов — отдельный модуль, его нужно загрузить дополнительно:

.. code-block:: tcl

   load libsurfit_io[info sharedlibextension]
   surf_save_grd "surface.grd" "map_area"

``map_name``, ``tol`` и ещё десяток настроек — это переменные, трассированные
в глобальные переменные движка, поэтому ``set tol 1e-6`` меняет допуск
решателя, а не локальную переменную скрипта.

Примеры
-------

В ``examples/surfit/tests`` лежат 35 небольших скриптов, по одному на семейство
правил, а в ``examples/surfit/realworld`` — 29 более крупных на реальных данных.
Некоторые каталоги представляют собой конвейеры: ``04_thickness_surface.tcl``
читает файлы, которые записал ``02_top_surface.tcl``, а ``00_run_all.tcl``
запускает их по порядку.

Связь с Python
--------------

Привязки Python предоставляют те же команды под теми же именами, так что
скрипт отображается вызов в вызов. ``src/pysurfit/tests/run_tcl_suite.py``
делает этот перевод механически и сравнивает выходные файлы побайтово;
подробности в :doc:`development`.

Два места не переводятся буквально:

* Tcl выполняет подстановку обратной косой черты внутри кавычек, поэтому
  ``"\t"`` — это символ табуляции. Транслятор обязан делать то же, иначе
  колонки будут прочитаны неверно.
* ``set`` для трассированной переменной — это вызов внутрь движка, а не
  присваивание.

Шероховатости
-------------

* ``surf_plot`` рисует PostScript через встроенную библиотеку CreEPS. Привязки
  Python для неё нет; питоновской стороне больше подошёл бы просмотрщик в
  браузере.
* В файле ``Hints`` рекомендуется Tcl 8.5. Этот совет устарел: современные
  дистрибутивы поставляют 8.6, и код с ней собирается.
* Tcl-плагины ``globe`` и ``freeflow`` сгенерированы SWIG 1.3.28 и лежат в
  репозитории как ``*_wrap.cxx``: сборка компилирует именно их, а не объявления
  в ``interface/*.i``. Правка ``.i`` там ничего не меняет, пока обёртка не
  перегенерирована, и расхождение обнаруживается молча. С ``*.i`` самого движка
  (``src/tclsurfit/src``) дело другое: они прогоняются через SWIG при каждой
  сборке.
