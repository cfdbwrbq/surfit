Установка
=========

Требования
----------

Для сборки движка нужны:

* CMake 3.10 или новее;
* компилятор C++.

И это всё. Зависимости от Tcl у движка нет: сопоставление имён объектов
реализовано на месте, а логирование пишет в stdio и в хук.

Tcl-*фронтенд* необязателен и по умолчанию выключен. Для его сборки
дополнительно нужны заголовки Tcl (пакет ``tcl-dev`` в Debian и Ubuntu) и SWIG;
см. `Параметры сборки`_.

Дополнительно, для отдельных возможностей:

* ``zlib`` — модуль ``globe`` для глобальных тайлов DEM;
* ``libjpeg`` — сетки в JPEG;
* ``netcdf`` — сетки GMT и netCDF.

Python
------

Пакету нужен numpy:

.. code-block:: bash

   pip install .

Та же команда работает и из копии репозитория. Собираются только движок и
привязки; если нужен ещё и Tcl-фронтенд, смотрите `Параметры сборки`_. Колесо
несёт все разделяемые библиотеки внутри пакета, поэтому ничего не нужно
прописывать в ``LD_LIBRARY_PATH``.

Из исходников
-------------

.. code-block:: bash

   mkdir -p build && cd build
   cmake ../src
   make -j"$(nproc)"
   export LD_LIBRARY_PATH="$PWD/bin:$LD_LIBRARY_PATH"

На выходе получаются библиотеки движка, библиотека форматов
``libsurfit_io_core.so`` и — если найден pybind11 — расширение Python внутри
``bin/surfit/``. С ``SURFIT_BUILD_TCL=ON`` добавляются ещё Tcl-модуль
``libtclsurfit.so``, интерпретатор командной строки ``surfit``, подпроекты
``globe`` и ``freeflow`` и Tcl-плагин форматов ``libsurfit_io.so``.

Чтобы поставить в префикс, ``make install`` кладёт библиотеки в ``lib``, а
интерпретатор в ``bin``. RPATH не прописывается, поэтому ``lib`` должна быть в
путях загрузчика — отсюда ``LD_LIBRARY_PATH`` в командах выше.

Параметры сборки
----------------

.. list-table::
   :header-rows: 1
   :widths: 28 12 60

   * - Параметр
     - По умолчанию
     - Значение
   * - ``SURFIT_BUILD_TCL``
     - ``OFF``
     - Собирать Tcl-модуль, интерпретатор командной строки, ``globe``,
       ``freeflow`` и Tcl-плагин форматов. Требует Tcl и SWIG.
   * - ``SURFIT_BUILD_PYTHON``
     - ``ON``
     - Собирать расширение Python. Если pybind11 нет, шаг пропускается с
       сообщением.
   * - ``SURFIT_PYTHON_WHEEL``
     - ``OFF``
     - Ставить все разделяемые библиотеки внутрь пакета ``surfit``, а не в
       ``lib``. Включается при сборке колеса.
   * - ``SURFIT_LIBDIR``
     - ``lib``
     - Куда ставить разделяемые библиотеки. Для колеса становится ``surfit``.

Например, сборка только с привязками Python:

.. code-block:: bash

   cmake -DSURFIT_BUILD_TCL=OFF ../src

Документация
------------

Документация собирается Sphinx на двух языках, английском и русском:

.. code-block:: bash

   pip install -r docs/requirements.txt
   docs/build.sh

Результат — ``docs/_build/html/index.html``, который перенаправляет на
английское дерево; русское доступно одним нажатием через переключатель внизу
каждой страницы.
