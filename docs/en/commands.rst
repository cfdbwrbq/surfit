Command reference
=================

Every command of the Tcl front end, in alphabetical order: the list is read
from the SWIG interface files under ``src``, and the syntax, description,
parameters and example come from the Doxygen comments in the headers.  The
Python package exposes the same names (``import surfit; surfit.area_read(...)``,

``area``
    **Syntax:** ``area value area_name inside``

    Using this rule the resulting surface approximates area with constant
    "value" in least squares meaning. Value can be set to any real number or
    "undef".

    * **value** — real number for surface approximation in area (default:
      ``"undef"``)
    * **area_name** — name of area dataset (default: ``"*"``)
    * **inside** — if inside is equal to 1, then surface will be
      approximated inside area, else outside (default: ``1``)

``area_add``
    **Syntax:** ``area_add value weight area_name inside``

    This function modifies previous (modifiable) rule by adding the area
    rule with some weight. Use this rule if you don't know "value" exactly.
    Using this rule the resulting surface approximates area with "value"
    taking into account a previous (modifiable) rule.

    * **value** — real number for surface approximation in area
    * **weight** — informational weight for this rule
    * **area_name** — name of area dataset (default: ``"*"``)
    * **inside** — if inside is equal to 1, then surface will be
      approximated inside area, else outside (default: ``1``)

``area_completer``
    **Syntax:** ``area_completer area_name D1 D2 alpha w inside``

    * **area_name** — area name (default: ``"*"``)
    * **D1** — weight coefficient for rule that the resulting surface should
      tend to constant surface (default: ``1``)
    * **D2** — weight coefficient for rule that the resulting surface should
      tend to plane surface (default: ``2``)
    * **alpha** — anisotropy angle (degrees) (default: ``0``)
    * **w** — anisotropy factor (default: ``1``)
    * **inside** — if inside is equal to 1, then area_completer will work
      inside area, else outside (default: ``1``)

``area_completer_add``
    **Syntax:** ``area_completer_add weight area_name D1 D2 alpha w inside``

    * **weight** — weight coefficient. This gridding rule will be added with
      this weight coefficient to previous gridding rule. (default: ``1``)
    * **area_name** — area name (default: ``"*"``)
    * **D1** — weight coefficient for rule that the resulting surface should
      tend to constant surface (default: ``1``)
    * **D2** — weight coefficient for rule that the resulting surface should
      tend to plane surface (default: ``2``)
    * **alpha** — anisotropy angle (degrees) (default: ``0``)
    * **w** — anisotropy factor (default: ``1``)
    * **inside** — if inside is equal to 1, then area_completer will work
      inside area, else outside (default: ``1``)

    **Syntax:** ``area_geq value area_name penalty_factor inside``

    This rule adds the surface condition - "the resulting surface in area
    should be greater than or equal to value".

    * **value** — resulting surface values should be greater than or equal
      to this real number
    * **area_name** — name of area dataset (default: ``"*"``)
    * **penalty_factor** — parameter for penalty (default: ``0``)
    * **inside** — if inside is equal to 1, then surface values should be
      greater than or equal to value inside area, else outside (default:
      ``1``)
